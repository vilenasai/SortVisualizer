# Визуализатор алгоритмов сортировки

Приложение-портфолио на **WPF (C#)**, в котором реализованы 5 алгоритмов сортировки с визуализацией и статистикой.

## Возможности

- **5 алгоритмов сортировки:**
  - Пузырьковая (обмены)
  - Вставочная
  - Шейкерная
  - Быстрая (Хоара)
  - Болотная (BogoSort)
- **Направление:** по возрастанию / по убыванию
- **Три режима генерации массива:**
  - Среднее значение (равномерное распределение)
  - Табличная (шаг + шум)
  - Ручной ввод
- **Массив любого размера** (на экране — первые 50 чисел)
- **Замер времени** (мс) и **количества итераций** (до сотых)
- **Пиковые значения** — итераций/мс
- **Определение самого быстрого алгоритма** (зелёная подсветка)
- **Отмена сортировки**
- **Загрузка данных из Excel (.xlsx)**
- **Загрузка данных из Google Sheets** (через CSV)
- **Множественный запуск** — можно выбрать несколько алгоритмов и сравнить их

## Технологии

- **C# / .NET 8** (WPF)
- **ClosedXML** — чтение Excel
- **HttpClient** — загрузка CSV из Google Sheets
