# Портфолио — C# / WPF

Три работы в одном решении `SortVisualizer`. Запуск: `F5`.

## 🧭 Меню
- **Плитка 1** — Сортировки
- **Плитка 2** — Дихотомия (поиск корня)
- **Плитка 3** — Золотое сечение (поиск экстремума и корней)

---

## 📊 Работа 1 — Сортировки
- **5 алгоритмов:** Пузырьковая, Вставочная, Шейкерная, Быстрая, Bogo
- **Направление:** ↑ / ↓
- **3 режима:** Среднее / Табличная (DataGrid + CSV/XLSX) / Ручной
- **Загрузка:** Excel + Google Sheets
- Время (мс) и итерации, подсветка быстрого
- Отмена, защита Bogo (n>8), целые числа, до 1000 элементов

| Алгоритм | Считает |
|---|---|
| Пузырьковая | проходы (n−1) |
| Вставочная | сравнения |
| Шейкерная | проходы (n/2) |
| Быстрая | сравнения в Partition |
| Bogo | перемешивания |

---

## 📈 Работа 2 — Дихотомия (поиск корня)
- Поиск корня `f(x) = 0` на `[a, b]` с точностью `e`
- Парсинг формул через **NCalc** (`sin`, `cos`, `log`, `sqrt`, `pow`, ...)
- График на Canvas + точка корня + нулевая линия
- Проверка смены знака: 0 / 1 / 2+ корней → предупреждение
- Корень на границе — обработка
- Фильтр ввода: буквы не вводятся в `a`, `b`, `e`

**Пример:** `f(x)=sin(x)`, `a=1`, `b=4`, `e=0.001` → `x ≈ 3.1412`

---

## ⚖️ Работа 3 — Золотое сечение (поиск экстремума)
- Поиск **минимума** и **максимума** функции на `[a, b]`
- Поиск **корней** уравнения `f(x) = 0` через исследование модуля `|f(x)|`
- Поддержка возведения в степень (`^` → `Pow()`)
- График на Canvas с защитой от разрывов (адаптивный масштаб)
- Валидация ввода, защита от зацикливания, ограничение длины формулы

**Пример (Минимум):** `f(x) = x^2`, `a = -5`, `b = 5`, `e = 0.001` → `x ≈ 0.000`
**Пример (Корень):** `f(x) = x^2 - 4`, `a = 0`, `b = 3`, `e = 0.001` → `x ≈ 2.000`
