# Портфолио — C# / WPF

Две работы в одном решении `SortVisualizer`. Запуск: `F5`.

## 🧭 Меню

Плитка 1 — Сортировки. Плитка 2 — Дихотомия.

## 📊 Работа 1 — Сортировки

- 5 алгоритмов: Пузырьковая, Вставочная, Шейкерная, Быстрая, Bogo
- Направление ↑ / ↓
- 3 режима: Среднее / Табличная (DataGrid + CSV/XLSX) / Ручной
- Excel + Google Sheets
- Время (мс) и итерации, подсветка быстрого
- Отмена, защита Bogo (n>8), целые числа, до 1000 элементов

| Алгоритм | Считает |
|---|---|
| Пузырьковая | проходы (n−1) |
| Вставочная | сравнения |
| Шейкерная | проходы (n/2) |
| Быстрая | сравнения в Partition |
| Bogo | перемешивания |

## 📈 Работа 2 — Дихотомия

- Поиск минимума `f(x)` на `[a, b]` с точностью `e`
- Парсинг формул через **NCalc** (`sin`, `cos`, `log`, `sqrt`, `pow`, ...)
- График на Canvas + красная точка минимума
- 21 проверка валидации (числа, границы, разрыв функции)
- Фильтр ввода: буквы не вводятся в `a`, `b`, `e`

**Пример:** `f(x) = x*x - 4*x + 3`, `a = 0`, `b = 5`, `e = 0.001` → `x = 2, f = −1`
